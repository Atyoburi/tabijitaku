旅じたく PWA 配布用ファイル

1. GitHubで新しい公開リポジトリを作る（例: tabijitaku）。
2. このフォルダ内の6ファイルをリポジトリのルートにアップロードする。
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) を選んで保存。
4. 表示された https://ユーザー名.github.io/tabijitaku/ を友達に共有する。
5. iPhoneではSafariでURLを開き、共有 > ホーム画面に追加。

注意: 公開URLはまだ作成されていません。HTTPSで公開後にオフライン機能が使えます。
各端末のデータはlocalStorageに保存され、別端末と同期しません。ブラウザのデータ消去で消える場合があります。
